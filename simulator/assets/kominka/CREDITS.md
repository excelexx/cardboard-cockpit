# Kominka Modular Home Pack — Lite

Rice Studio Lab. MIT license: see LICENSE in this directory.
Source: https://store.godotengine.org/asset/rice-studio-lab/kominka-modular-home-pack-lite/

24 static modular assets and the publisher's exterior assembly layout. Converted
from GLB to glTF, shared textures deduplicated and reduced to 512 px for flight
viewing distances. Homes assembled from the supplied layout, repeated with
instanced rendering at 2× scale. Demo scripts are not included or executed.

Reproduction: download the Lite ZIP, extract under .downloads/kominka, then run
tools/prepare_kominka.py. The source archive is not required at runtime.
