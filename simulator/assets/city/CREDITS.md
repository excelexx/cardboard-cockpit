# Waterfront architecture

Both source kits are by **James Ray Cock**, published by **Poly Haven** under **CC0**:

- Modular Urban Apartments Facade: https://polyhaven.com/a/modular_urban_apartments_facade
- Modular Factory Facade: https://polyhaven.com/a/modular_factory_facade
- License: https://polyhaven.com/license

The included 1K glTF models, binary meshes and textures are used for waterfront apartments and port buildings. Selected modules are instanced into original layouts. Procedural architecture, terrain, roads, ships and bridge geometry are project code, not Microsoft Flight Simulator assets.

`tools/fetch_city_assets.py` provides reproducible downloads with checksum verification. Godot imports the local sources on first launch. Include binary mesh and texture files when redistributing the glTF sources.
