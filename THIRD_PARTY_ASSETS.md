# Third-party assets

No third-party model, texture, font, sound, or engine binary has been added at Phase 0.

Research candidates are listed in [docs/asset-sources.md](docs/asset-sources.md). A candidate listing is not proof that a file has been downloaded, inspected, or cleared for redistribution.

Before importing an asset, record:

1. Asset title, creator, original source URL and download date.
2. Exact license and version, with the bundled license file or a preserved source record.
3. Original filename, hash, and format.
4. Conversion, material, geometry, texture or other modifications.
5. Required attribution and any distribution restrictions.

Display required credits inside the app and preserve accompanying notices in source and packaged builds. Original model licenses remain applicable independently of any future project source-code license.
